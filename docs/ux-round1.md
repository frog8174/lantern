# UX 第一輪（已定案）

視覺規則見 `docs/design.md`。閱讀頁版面打樣：畫布第 5 板（檔案副本見派工說明）。

## A. 閱讀頁重新排版
- 頂列：`← <研究主題名>`（回到這篇所在的研究主題；從「全部論文」開的就回全部論文）、論文標題（標題字體、單行省略）、閱讀模式分段鈕（原文／譯文疊上／左右對照）、兩個工具（框選問 AI、自動畫重點）。帳號區、主題切換照全站規則（見 C）。
- 縮放與頁碼：移出頂列，改成 PDF 區右下角的**浮動小控制**（－ 120% ＋ 和 `4 / 10` 可輸入跳頁）。
- **頁面導軌**取代 PDF 區的預設捲軸：燈光段 = 目前可見範圍，旁邊頁碼；右側小刻度 = 有螢光筆或註解的頁；點刻度跳頁、拖燈光段捲動、點軌道跳到該位置。鍵盤：導軌可聚焦，上下鍵換頁。
- 左側只放「這篇」：大綱在最上（目前章節燈光色標示）、下面是同研究主題的其他論文（從「全部論文」開的就列全部）。匯入、全庫論文清單從閱讀頁移除（在研究主題頁做）。窄螢幕（< 900px）左側收成頂列一顆「大綱」按鈕，點開是抽屜。
- 右側面板改四個分頁：**讀懂**（摘要、解釋紀錄、問這篇的聊天，聊天輸入框固定在分頁底部，取消右下角浮動聊天泡泡）｜**我的筆記**（螢光筆、自動標註、註解；之後改名「標註」，另加「筆記」分頁，見 docs/notes-design.md）｜**文獻**（參考文獻、相關論文）｜**Wiki**（這篇的論文頁置頂，其餘提到它的頁面收合成「還有 N 頁提到這篇」）。保留可拖寬、可彈出。
- 選字工具列文字：解釋／翻譯／畫重點／寫註解／問 AI。

## B. 研究主題頁與流程
1. **上傳／匯入後留在研究主題頁**，不自動打開論文；新卡片出現在最前面。
2. **卡片顯示處理階段**（只在進行中顯示，安靜的小字＋燈光色）：取得書目中、翻譯中（沿用進度圈）。完成後消失。
3. **重複論文**：上傳或匯入時，若使用者庫中已有相同檔案（sha256）或相同 DOI／正規化標題，不另建一篇：回傳既有那篇，若是在某研究主題中上傳就把它加進該主題，前端提示「這篇已經在論文庫裡，已加入這個研究主題」。
4. **取代瀏覽器原生對話框**：新增研究主題、改名 → 就地輸入框（Enter 確認、Esc 取消）；arXiv 匯入 → 就地輸入框。不再用 `prompt()`。
5. **刪除仍按兩次**（研究主題、論文、移出、問答單題、清空對話）：第一下按鈕變成朱色並換成一句俚語提醒刪了救不回來，3 秒內再按才刪；俚語從一組輪替，例如「覆水難收，再按一次」「潑出去的水收不回來」「一去不復返，確定？」「船過水無痕，真的要刪？」「此去無回頭，再按一次」。不再用 `confirm()`。
